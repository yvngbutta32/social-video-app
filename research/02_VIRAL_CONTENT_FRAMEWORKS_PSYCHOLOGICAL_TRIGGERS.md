## 🧠 PSYCHOLOGICAL TRIGGERS THAT DRIVE VIRALITY

### **The 6 Core Viral Triggers (STEPPS Framework - Jonah Berger)**

| Trigger | Psychological Mechanism | Content Application | Platform Optimization |
|---------|------------------------|---------------------|----------------------|
| **Social Currency** | People share what makes them look good | Insider knowledge, exclusive access, early adoption | TikTok: "POV: You're in the 1% who knows this" |
| **Triggers** | Environmental cues prompt sharing | Daily routines, seasonal events, cultural moments | Reels: "Morning routine that changed my life" |
| **Emotion** | High-arousal emotions drive sharing | Awe, anger, anxiety, amusement, excitement | Shorts: Shocking result → "I couldn't believe it" |
| **Public** | Visible behavior is imitable | Social proof, user-generated content, challenges | TikTok: Duet/Stitch chains, "Show me your..." |
| **Practical Value** | Useful information gets shared | Tutorials, hacks, frameworks, templates, cheat sheets | Reels: "Save this for later" + carousel |
| **Stories** | Narratives carry ideas | Hero's journey, transformation, behind-the-scenes | LinkedIn: "How I built X from zero" |

### **High-Arousal vs Low-Arousal Emotions**

| High-Arousal (VIRAL) | Low-Arousal (NOT VIRAL) |
|---------------------|------------------------|
| **Awe** - "This changed everything" | Contentment - "Nice" |
| **Excitement** - "You won't believe this" | Sadness - "That's unfortunate" |
| **Anger/Outrage** - "This is wrong" | Relaxation - "Soothing" |
| **Anxiety/FOMO** - "Don't miss this" | Boredom - "Meh" |
| **Amusement/Joy** - "Had to share this" | Melancholy - "Bittersweet" |
| **Surprise** - "Plot twist!" | Indifference - "Okay" |

**Rule**: Only high-arousal emotions drive sharing. Every viral piece must hit ≥2 high-arousal emotions.

## 📐 VIRAL CONTENT FRAMEWORKS (Battle-Tested)

### **Framework 1: The "Pattern Interrupt" (TikTok/Reels/Shorts)**
```
Structure: [Pattern Interrupt 0-1s] → [Hook 1-3s] → [Value 3-15s] → [CTA 15-30s] → [Loop]

Pattern Interrupts:
- Visual: Unexpected movement, color flash, POV shift, text reveal
- Audio: Sound effect, voice change, silence, beat drop
- Cognitive: Counterintuitive statement, question, shocking stat
- Narrative: "Wait for it...", "You're doing it wrong", "Stop scrolling"

Examples:
- Fitness: [Person failing lift] → "Your form is killing gains" → Fix demo → "Save this"
- Business: [Burning $100 bill] → "This is what bad hiring costs" → Framework → "Part 2 tomorrow"
- Beauty: [Messy application] → "Wrong way vs Right way" → Perfect result → "Products in bio"
```

### **Framework 2: The "Curiosity Gap" (All Platforms)**
```
Structure: [Knowledge Gap] → [Tease Solution] → [Deliver Value] → [Open New Gap]

Gap Types:
- Information: "The one setting pros use that amateurs ignore"
- Process: "How I edit in 5 minutes (not 5 hours)"
- Result: "From 0 to 100K followers in 30 days"
- Identity: "Why 99% of creators fail at this"
- Secret: "The tool top 1% creators don't want you to know"

Delivery: Must over-deliver on promise, then create next gap
```

### **Framework 3: The "Transformation Arc" (TikTok/Reels/Shorts/LinkedIn)**
```
Structure: [Before/Problem] → [Struggle/Process] → [Breakthrough] → [After/Result] → [How-To]

Variations:
- Micro: 15s (Before → After → "How")
- Mini: 60s (Problem → Attempt → Fail → Pivot → Success → Lesson)
- Macro: Series (Episode 1: Problem → Ep 2: Journey → Ep 3: Result → Ep 4: Template)

Key: Show the MESSY MIDDLE - perfection doesn't connect, struggle does
```

### **Framework 4: The "Contrarian Take" (X/LinkedIn/TikTok)**
```
Structure: [Common Belief] → [Why It's Wrong] → [Evidence] → [Better Approach] → [Challenge]

Formulas:
- "Everyone says X. Here's why X is killing your [results]..."
- "The [industry] lie you've been told: [belief]. Truth: [reality]..."
- "Stop [common advice]. Start [counterintuitive action] instead..."
- "Unpopular opinion: [controversial take]. Data: [proof]..."

Risk: Must be genuinely contrarian, not clickbait. Back with data/experience.
```

### **Framework 5: The "Insider Secret" (All Platforms)**
```
Structure: [Exclusivity Signal] → [Secret Revealed] → [Proof] → [Application] → [Access]

Exclusivity Signals:
- "My $50K mentor told me..."
- "The agency framework we charge $10K for..."
- "What the top 1% do differently..."
- "Leaked: [Company] internal doc shows..."
- "After analyzing 10,000 viral posts..."

Application: Give away 80% value, gate 20% (newsletter, course, community)
```

### **Framework 6: The "Challenge/Participation" (TikTok/Reels/Shorts)**
```
Structure: [Challenge Definition] → [Demo] → [Rules] → [Reward] → [UGC Loop]

Types:
- Skill: "Show me your best [skill]" → Duet chain
- Transformation: "30-day [habit] challenge" → Daily updates
- Creative: "Remix this sound with your [niche]" → UGC explosion
- Educational: "Explain [complex topic] in 15s" → Expert responses
- Controversial: "Unpopular opinion: [topic]. Change my mind." → Debate

Viral Mechanics: 
- Low barrier to entry
- High social reward for participation
- Algorithmic boost for duets/stitches/remixes
- Community formation around hashtag
```

### **Framework 7: The "Data-Driven Revelation" (LinkedIn/X/Long-form)**
```
Structure: [Hypothesis] → [Methodology] → [Surprising Data] → [Implications] → [Action Items]

Sources:
- Platform analytics (your own + competitors)
- Survey data (audience polls)
- Third-party reports (industry)
- A/B test results
- Case study metrics

Format: "I analyzed [X] posts/videos/accounts. Here's what [metric] actually correlates with..."
```

### **Framework 8: The "Storytelling Formula" (All Platforms)**
```
Pixar/Disney Structure (Adapted for Short-Form):
1. Once upon a time... [Context/Status Quo]
2. Every day... [Routine/Problem]
3. One day... [Inciting Incident/Discovery]
4. Because of that... [Action/Struggle]
5. Because of that... [Escalation/Complication]
6. Until finally... [Climax/Breakthrough]
7. And ever since... [New Reality/Lesson]
7b. And that's why... [CTA/Application]

Compressed for 15-60s:
- 0-1s: "I was stuck at [problem]" (Once/Every day)
- 1-3s: "Then I discovered [insight]" (One day)
- 3-10s: "Tried [X], failed. Tried [Y], worked" (Because/Because)
- 10-15s: "Now [result]" (Until finally)
- 15-20s: "Here's exactly how..." (And ever since)
- 20-30s: "Save this / Follow for more" (CTA)
```

## 🔬 HOOK TESTING METHODOLOGY (Our A/B Framework)

### **Hook Generation Pipeline**
```javascript
// For each concept, generate 10 hook variants across archetypes
const hookArchetypes = [
  'result_first', 'pattern_break', 'contrast', 'process_reveal',
  'text_overlay', 'pov_camera', 'sound_effect', 'voice_change',
  'question', 'controversial', 'trending_sound', 'asmr',
  'numbered_list', 'how_to', 'mistake_warning', 'secret_insider',
  'transformation', 'question_text'
];

async function generateHooks(concept, niche, platform, count = 10) {
  const hooks = [];
  
  for (const archetype of hookArchetypes.slice(0, count)) {
    const hook = await aiGenerateHook({
      concept,
      niche,
      platform,
      archetype,
      platformBestPractices: getPlatformHookRules(platform),
      nicheLanguage: getNicheVocabulary(niche)
    });
    hooks.push({ archetype, ...hook });
  }
  
  return hooks;
}
```

### **Bayesian A/B Testing (Auto-Stop)**
```javascript
// Multi-armed bandit with Thompson Sampling
class HookABTest {
  constructor(hooks, minSample = 100, confidence = 0.95) {
    this.hooks = hooks.map(h => ({ ...h, alpha: 1, beta: 1, views: 0, conversions: 0 }));
    this.minSample = minSample;
    this.confidence = confidence;
  }
  
  selectHook() {
    // Thompson Sampling: sample from Beta(alpha, beta) for each hook
    const samples = this.hooks.map(h => ({
      hook: h,
      sample: this.betaSample(h.alpha, h.beta)
    }));
    return samples.sort((a, b) => b.sample - a.sample)[0].hook;
  }
  
  recordView(hookId) {
    const hook = this.hooks.find(h => h.id === hookId);
    hook.views++;
  }
  
  recordConversion(hookId) {
    const hook = this.hooks.find(h => h.id === hookId);
    hook.conversions++;
    hook.alpha = 1 + hook.conversions;
    hook.beta = 1 + hook.views - hook.conversions;
  }
  
  getWinner() {
    // Check if any hook has statistically significant lead
    const sorted = this.hooks.sort((a, b) => 
      (b.conversions / b.views) - (a.conversions / a.views)
    );
    
    const best = sorted[0];
    const second = sorted[1];
    
    if (best.views < this.minSample) return null;
    
    const pValue = this.calculatePValue(best, second);
    if (pValue < (1 - this.confidence)) {
      return best;
    }
    return null; // No winner yet
  }
}
```
